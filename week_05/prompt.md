## **<span style="color:#1ED2C8;">프롬프트 작성 요령 및 준수 사항</span>**
1. 구현할 아트워크의 캔버스 크기, 오브젝트, 색, 움직임, 인터랙션 등을 정리하고 지시할 것.
2. 사용할 알고리즘 물감(로직)을 디테일하게 정의하고 올바른 용어를 사용해서 지시할 것.
3. 지시 순서는 캔버스 설정 > 오브젝트 묘사 > 애니메이션 >  인터랙션 설명 순으로 할 것.
4. 마음에 들지 않는 결과가 계속 반복된다면 새로운 채팅 창이나 다른 LLM에서 새로 시작할 것. 
5. 수정 요청 시 전체를 바꾸어버리는 경우가 있으므로 부분만 수정 요청하거나, 수정하면 안되는 영역을 설정할 것.
6. AI가 짠 코드에는 오류가 있을 수 있으므로 필요시 다른 LLM을 이용하여 refactoring을 요청할 것.
7. 설명 주석을 요청하여 사용한 로직, 알고리즘과 함수의 의미를 파악할 것. 
8. AI가 짜 준 아트워크에 만족하지 말고, 내 입맛에 맞게 변수의 값을 바꾸어 볼 것.
9. 참고할 이미지를 업로드할 때는 어느 부분을 참고해서 만들지, 개선할지 등을 자세히 지시할 것. (첨부 용량 주의)
10. 다른 사람이 만든 코드를 활용할 때에는 AI에게 코드의 로직을 물어보고 파악한 후 필요한 부분만 사용할 것. (저작권 여부 확인)

## **<span style="color:#f49571;">예시 프롬프트 1 - 맥박</span>**

1. 캔버스 크기는 1920 x 1080 (16:9 가로형)으로 설정해줘.
2. 배경은 어두운 회색으로 해줘.
3. 화면 중앙에 큰 원 하나를 그려줘. 이 원의 크기가 계속 커졌다 작아지는 움직임을 만들어야 해.
4. sin 함수를 사용해서 원의 지름이 시간에 따라 50부터 200 사이를 주기적으로 변하도록 해줘. (마치 심장 박동처럼)
5. 원의 색상은 밝은 빨강이나 핑크색으로 해줘. 투명도도 조금씩 변하면서 움직이는 느낌이 나도록.
6. 원의 개수는 1개만 유지하되, 배경에 희미한 자취가 남도록 낮은 투명도의 추적 효과를 넣어도 괜찮아.
7. 애니메이션은 계속 반복되게 하되, 인터랙션은 없이 자동으로만 움직이도록 작성해줘.

## **<span style="color:#f49571;">예시 프롬프트 2 - 떨림</span>**

1. 캔버스 크기는 800 x 800 (1:1 정사각형)으로 설정해줘.
2. 배경은 진한 파랑이나 보라색으로 해줘.
3. 화면 중앙에 여러 개의 작은 원들을 규칙적으로 배치해줘. (예: 5개 정도를 원형으로)
4. sin 함수를 사용해서 각 원의 위치가 미세하게 떨리는 것처럼 보이게 해줘. 떨림의 정도는 작지만 지속적이어야 해.
5. 원의 색상은 밝은 하늘색이나 옅은 보라색으로 하고, 투명도도 약간씩 변하도록.
6. 각 원의 떨림 타이밍을 조금씩 다르게 해서 전체적으로 파동이 흐르는 듯한 느낌이 나도록 해줘.
7. 인터랙션과 애니메이션은 자동으로만 실행되고, 마우스나 키보드 입력은 받지 않도록 작성해줘.

## **<span style="color:#f49571;">예시 프롬프트 3 - 긴장감</span>**

1. 캔버스 크기는 720 x 1280 (9:16 세로형)으로 설정해줘.
2. 배경은 검은색으로 해줘.
3. 화면 좌우 양쪽에 길쭉한 직선들(또는 막대)을 여러 개 그려줘. 마치 음파나 진동이 퍼져나가는 것처럼.
4. 각 직선의 높이나 길이가 sin 함수를 사용해서 시간에 따라 계속 변하도록 해줘.
5. 직선들의 색상은 밝은 노란색이나 흰색으로 해서 검은 배경과 뚜렷한 대비를 만들어줘.
6. 직선들이 주기적으로 커졌다 작아졌다를 반복하되, 각 직선마다 타이밍을 약간씩 달리해서 파도치는 느낌을 표현해줘.
7. 마우스를 캔버스에 올리면 그 지점에서 직선들의 떨림이 더 강해지는 인터랙션을 추가해줘. (mouseX, mouseY 활용)
8. 마우스를 치울 때는 다시 원래의 떨림으로 돌아가도록 해줘.
