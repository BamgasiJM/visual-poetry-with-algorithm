## **<span style="color:#1ED2C8;">프롬프트 작성 요령 및 준수 사항</span>**
1. 구현할 아트워크의 캔버스 크기, 오브젝트, 색, 움직임, 인터랙션 등을 정리하고 지시할 것.
2. 사용할 알고리즘 물감(로직)을 디테일하게 정의하고 올바른 용어를 사용해서 지시할 것.
3. 지시 순서는 캔버스 설정 > 오브젝트 묘사 > 애니메이션 >  인터랙션 설명 순으로 할 것.
4. 마음에 들지 않는 결과가 계속 반복된다면 새로운 채팅 창이나 다른 LLM에서 새로 시작할 것. 
5. 수정 요청 시 전체를 바꾸어버리는 경우가 있으므로 부분만 수정 요청하거나, 수정하면 안되는 영역을 설정할 것.
6. AI가 짠 코드에는 오류가 있을 수 있으므로 필요시 다른 LLM을 이용하여 refactoring을 요청할 것.
7. 설명 주석을 요청하여 사용한 로직, 알고리즘과 함수의 의미를 파악할 것. 
8. AI가 짜 준 아트워크에 만족하지 말고, 내 입맛에 맞게 변수의 값을 바꾸어 볼 것.
9. 참고할 이미지를 업로드할 때는 어느 부분을 참고해서 만들지, 개선할지 등을 자세히 지시할 것. (첨부 용량 주의)
10. 다른 사람이 만든 코드를 활용할 때에는 AI에게 코드의 로직을 물어보고 파악한 후 필요한 부분만 사용할 것. (저작권 여부 확인)

## **<span style="color:#f49571;">예시 프롬프트 1 - 떠다니는 단어</span>**

1. 캔버스 크기는 1920 x 1080 (16:9 가로형)으로 설정해줘.
2. 배경은 검은색으로 해줘.
3. "사랑", "그리움", "외로움" 같은 감정 단어들을 화면에 여러 개 배치해줘. (5~7개 정도)
4. 각 글자는 개별적으로 움직이는데, 위치와 크기가 sin 함수를 사용해서 천천히 변하도록 애니메이션을 추가해줘.
5. 글자의 색상은 밝은 분홍색이나 옅은 보라색으로 하고, 크기가 변할 때 투명도도 함께 변하도록.
6. 글자들이 겹치지 않도록 각각의 움직이는 영역을 다르게 설정해줘.
7. 인터랙션은 없이 자동으로 반복되도록 작성해줘.

## **<span style="color:#f49571;">예시 프롬프트 2 - 산란하는 글자</span>**

1. 캔버스 크기는 800 x 800 (1:1 정사각형)으로 설정해줘.
2. 배경은 밝은 회색이나 옅은 파란색으로 해줘.
3. "행복", "슬픔", "분노" 같은 감정 단어들을 for 반복문으로 여러 개 생성해줘. (20개 정도)
4. 각 글자의 위치는 랜덤하게 배치하되, 글자 크기도 다양하게 해줘.
5. 글자의 색상은 무지개처럼 다양한 색으로 표현하되, 크기가 클수록 더 밝게.
6. 글자들이 정적이면서도 약간의 회전을 가지도록 해서 동적인 느낌을 표현.
7. 인터랙션과 애니메이션은 없이 정적인 결과만 나오도록 작성해줘.

## **<span style="color:#f49571;">예시 프롬프트 3 - 마음의 울림</span>**

1. 캔버스 크기는 720 x 1280 (9:16 세로형)으로 설정해줘.
2. 배경은 검은색으로 해줘.
3. "기다림", "만남", "이별" 같은 관계 관련 단어들을 화면에 배치해줘.
4. 각 글자는 sin 함수를 사용해서 위치와 크기가 천천히 변하며 움직이도록 애니메이션을 추가.
5. 글자의 색상은 따뜻한 톤(주황, 분홍)으로 하되, 글자 주변에 흐린 아우라(투명한 원)가 맴도는 효과를 추가해줘.
6. 마우스를 캔버스 위에 올리면 글자들이 마우스 쪽으로 끌려가거나 반대로 떨어지도록 인터랙션을 추가해줘.
7. 마우스의 위치에 따라 글자들의 움직임이 동적으로 반응하게 해줘.
