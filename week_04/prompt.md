## **<span style="color:#1ED2C8;">프롬프트 작성 요령 및 준수 사항</span>**
1. 구현할 아트워크의 캔버스 크기, 오브젝트, 색, 움직임, 인터랙션 등을 정리하고 지시할 것.
2. 사용할 알고리즘 물감(로직)을 디테일하게 정의하고 올바른 용어를 사용해서 지시할 것.
3. 지시 순서는 캔버스 설정 > 오브젝트 묘사 > 애니메이션 >  인터랙션 설명 순으로 할 것.
4. 마음에 들지 않는 결과가 계속 반복된다면 새로운 채팅 창이나 다른 LLM에서 새로 시작할 것. 
5. 수정 요청 시 전체를 바꾸어버리는 경우가 있으므로 부분만 수정 요청하거나, 수정하면 안되는 영역을 설정할 것.
6. AI가 짠 코드에는 오류가 있을 수 있으므로 필요시 다른 LLM을 이용하여 refactoring을 요청할 것.
7. 설명 주석을 요청하여 사용한 로직, 알고리즘과 함수의 의미를 파악할 것. 
8. AI가 짜 준 아트워크에 만족하지 말고, 내 입맛에 맞게 변수의 값을 바꾸어 볼 것.
9. 참고할 이미지를 업로드할 때는 어느 부분을 참고해서 만들지, 개선할지 등을 자세히 지시할 것. (첨부 용량 주의)
10. 다른 사람이 만든 코드를 활용할 때에는 AI에게 코드의 로직을 물어보고 파악한 후 필요한 부분만 사용할 것. (저작권 여부 확인)

## **<span style="color:#f49571;">예시 프롬프트 1 - 격자 패턴</span>**

1. 캔버스 크기는 800 x 800으로 설정해줘.
2. 배경은 밝은 회색이나 베이지색으로 해줘.
3. for 반복문을 사용해서 작은 원들을 4행 4열로 규칙적으로 배치해줘. 각 원 사이의 간격은 일정하게 유지해.
4. 원의 지름은 50~60 정도로 하되, 배치할 때 약간의 랜덤한 투명도를 적용해서 너무 딱딱하지 않게 해줘.
5. 색상은 차분한 파랑이나 초록색 한 가지만 사용해줘.
6. 인터랙션과 애니메이션은 없이 정적인 결과만 나오도록 작성해줘.

## **<span style="color:#f49571;">예시 프롬프트 2 - 수직 줄무늬</span>**

1. 캔버스 크기는 600 x 800으로 설정해줘.
2. 배경은 진한 회색으로 해줘.
3. for 반복문을 사용해서 위에서 아래로 길게 이어지는 세로 선들을 여러 개 그려줘. 모든 선의 길이는 같고 간격도 일정하게.
4. 선의 색상은 밝은 회색이나 흰색으로 해서 배경과 명확한 대비를 만들어줘.
5. 각 선의 굵기(strokeWeight)는 3~5 정도로 해주고, 투명도를 조금씩 다르게 해줘.
6. 선들의 개수는 10~15개 정도로 해서 화면 전체에 균등하게 분포시켜줘.
7. 인터랙션과 애니메이션은 없이 정적인 결과만 나오도록 작성해줘.

## **<span style="color:#f49571;">예시 프롬프트 3 - 중첩 사각형</span>**

1. 캔버스 크기는 800 x 800으로 설정해줘.
2. 배경은 검은색으로 해줘.
3. 화면의 중앙을 기준으로 반복문을 사용해서 점점 커지는 사각형들을 그려줘. (정사각형이 사각형 안에 사각형이 들어가는 형태)
4. 가장 안쪽 사각형부터 가장 바깥쪽 사각형까지 10개 정도의 사각형이 있으면 좋아. 각 사각형 사이의 간격은 일정하게 해줘.
5. 사각형의 색상은 밝은 파랑에서 옅은 파랑으로 조금씩 변화하도록 해줘. 선만 그려서(fill 없이) 테두리만 보이게 해줘.
6. 선의 굵기는 2~3 정도로 하고, 투명도를 조금씩 다르게 해서 깊이감을 만들어줘.
7. 인터랙션과 애니메이션은 없이 정적인 결과만 나오도록 작성해줘.
