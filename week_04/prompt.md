## **✅ 필수 지시 문장**

p5.js로 제너레이티브 아트워크를 만들기 위한 코드를 작성해줘.<br/>

1. p5.js 에디터에서 실행할 것이므로 instance mode가 아닌 global mode로 작성해줘.
2. HTML, CSS 파일 없이 JavaScript 코드만 작성해줘.
3. React 같은 외부 라이브러리는 사용하지 말고 순수한 JavaScript만 사용해줘.
4. 나는 코딩 경험이 없으므로쉬운 한글 주석을 달아줘. 각 함수와 변수와 메서드의 용도를 설명해줘.<br/>
