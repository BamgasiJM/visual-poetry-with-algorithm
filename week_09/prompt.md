## **<span style="color:#1ED2C8;">프롬프트 작성 요령 및 준수 사항</span>**
1. 구현할 아트워크의 캔버스 크기, 오브젝트, 색, 움직임, 인터랙션 등을 정리하고 지시할 것.
2. 사용할 알고리즘 물감(로직)을 디테일하게 정의하고 올바른 용어를 사용해서 지시할 것.
3. 지시 순서는 캔버스 설정 > 오브젝트 묘사 > 애니메이션 >  인터랙션 설명 순으로 할 것.
4. 마음에 들지 않는 결과가 계속 반복된다면 새로운 채팅 창이나 다른 LLM에서 새로 시작할 것. 
5. 수정 요청 시 전체를 바꾸어버리는 경우가 있으므로 부분만 수정 요청하거나, 수정하면 안되는 영역을 설정할 것.
6. AI가 짠 코드에는 오류가 있을 수 있으므로 필요시 다른 LLM을 이용하여 refactoring을 요청할 것.
7. 설명 주석을 요청하여 사용한 로직, 알고리즘과 함수의 의미를 파악할 것. 
8. AI가 짜 준 아트워크에 만족하지 말고, 내 입맛에 맞게 변수의 값을 바꾸어 볼 것.
9. 참고할 이미지를 업로드할 때는 어느 부분을 참고해서 만들지, 개선할지 등을 자세히 지시할 것. (첨부 용량 주의)
10. 다른 사람이 만든 코드를 활용할 때에는 AI에게 코드의 로직을 물어보고 파악한 후 필요한 부분만 사용할 것. (저작권 여부 확인)

## **<span style="color:#f49571;">예시 프롬프트 1 - 터지는 폭발</span>**

1. 캔버스 크기는 1920 x 1080 (16:9 가로형)으로 설정해줘.
2. 배경은 검은색으로 해줘.
3. 화면 중앙의 한 점에서 작은 파티클(입자)들이 폭발하듯 퍼져나가는 모습을 만들어줘.
4. 각 파티클은 초기 속도를 가지고 방사형으로 퍼져나가되, 시간에 따라 속도가 감소하도록 (중력이나 마찰력 효과).
5. 파티클의 색상은 밝은 노랑, 주황, 빨강의 따뜻한 계열로 하고, 멀어질수록 색이 어두워지도록.
6. 파티클이 화면 끝에 닿으면 사라지고 계속 새로운 파티클이 중앙에서 생성되도록.
7. 인터랙션은 없이 자동으로 계속 반복되도록 작성해줘.

## **<span style="color:#f49571;">예시 프롬프트 2 - 흐르는 생각</span>**

1. 캔버스 크기는 800 x 800 (1:1 정사각형)으로 설정해줘.
2. 배경은 밝은 회색이나 옅은 파란색으로 해줘.
3. 화면 좌측 아래에서 우측 상단으로 흐르는 입자들의 흐름을 만들어줘. (마치 강물이 흘러가는 것처럼)
4. 각 파티클이 생성되면 초기 속도를 가지고 이동하되, 약간의 랜덤 값을 더해서 자연스러운 흐름을 표현.
5. 파티클의 색상은 밝은 파란색이나 옅은 초록색으로 하고, 나이를 먹을수록 투명해지다가 사라지도록.
6. 화면에는 항상 200~300개 정도의 파티클이 동시에 존재하면서 지속적인 흐름을 유지.
7. 인터랙션과 마우스 입력은 없도록 작성해줘.

## **<span style="color:#f49571;">예시 프롬프트 3 - 확산하는 감정</span>**

1. 캔버스 크기는 720 x 1280 (9:16 세로형)으로 설정해줘.
2. 배경은 검은색으로 해줘.
3. 화면 중앙 아래쪽에서 시작하는 입자들이 위로 퍼져나가면서 흐르는 모습을 표현해줘.
4. 각 파티클이 생성되면 약간의 수평 방향 랜덤 이동을 더하면서 위로 올라가도록.
5. 파티클의 색상은 밝은 분홍색이나 핑크색으로 하고, 위로 올라갈수록 투명해지도록.
6. 마우스를 캔버스 위에 올리면 그 지점에 강한 흡입력이 생겨서 파티클들이 마우스 방향으로 끌려가도록 인터랙션을 추가해줘. (거리에 따라 영향력 조절)
7. 마우스가 움직일 때마다 파티클들이 동적으로 반응하게 해줘.
