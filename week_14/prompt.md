## **<span style="color:#1ED2C8;">프롬프트 작성 요령 및 준수 사항</span>**
1. 구현할 아트워크의 캔버스 크기, 오브젝트, 색, 움직임, 인터랙션 등을 정리하고 지시할 것.
2. 사용할 알고리즘 물감(로직)을 디테일하게 정의하고 올바른 용어를 사용해서 지시할 것.
3. 지시 순서는 캔버스 설정 > 오브젝트 묘사 > 애니메이션 >  인터랙션 설명 순으로 할 것.
4. 마음에 들지 않는 결과가 계속 반복된다면 새로운 채팅 창이나 다른 LLM에서 새로 시작할 것. 
5. 수정 요청 시 전체를 바꾸어버리는 경우가 있으므로 부분만 수정 요청하거나, 수정하면 안되는 영역을 설정할 것.
6. AI가 짠 코드에는 오류가 있을 수 있으므로 필요시 다른 LLM을 이용하여 refactoring을 요청할 것.
7. 설명 주석을 요청하여 사용한 로직, 알고리즘과 함수의 의미를 파악할 것. 
8. AI가 짜 준 아트워크에 만족하지 말고, 내 입맛에 맞게 변수의 값을 바꾸어 볼 것.
9. 참고할 이미지를 업로드할 때는 어느 부분을 참고해서 만들지, 개선할지 등을 자세히 지시할 것. (첨부 용량 주의)
10. 다른 사람이 만든 코드를 활용할 때에는 AI에게 코드의 로직을 물어보고 파악한 후 필요한 부분만 사용할 것. (저작권 여부 확인)

## **<span style="color:#f49571;">예시 프롬프트 1 - 점진적 진화</span>**

1. 캔버스 크기는 1920 x 1080 (16:9 가로형)으로 설정해줘.
2. 배경은 밝은 회색으로 해줘.
3. 화면에 여러 개의 원들(개체)을 배치하되, 각 원의 색상은 랜덤하게 생성돼야 해.
4. 매 프레임마다 특정 목표 색상(예: 파란색)에 가장 가까운 원들을 선택해서 더 큰 크기로 그려줘.
5. 시간이 지나면서 원들이 점점 목표 색상에 가까워지도록, 좋은 특성은 유지되고 나쁜 특성은 사라지게 해줘.
6. 화면에는 진화의 과정이 보이도록, 초반에는 다양한 색상이 있다가 점점 원하는 색상으로 수렴하는 모습을 표현.
7. 인터랙션은 없이 자동으로 진화하도록 작성해줘.

## **<span style="color:#f49571;">예시 프롬프트 2 - 형태의 수렴</span>**

1. 캔버스 크기는 800 x 800 (1:1 정사각형)으로 설정해줘.
2. 배경은 검은색으로 해줘.
3. 화면에 여러 개의 삼각형들을 배치하되, 각 삼각형의 회전 각도는 랜덤하게 시작해줘.
4. 목표 형태(정삼각형을 특정 각도에 맞춘 것)를 설정하고, 매 세대마다 목표에 가장 가까운 삼각형들을 선택해줘.
5. 좋은 유전자(각도)를 가진 개체들이 더 밝게 표현되고, 세대를 거쳐 갈수록 모두가 비슷한 각도로 수렴하게 해줘.
6. 삼각형들의 색상은 파란색 계열로 하되, 적합도가 높을수록 더 밝게.
7. 인터랙션과 마우스 입력은 없도록 작성해줘.

## **<span style="color:#f49571;">예시 프롬프트 3 - 상호 진화</span>**

1. 캔버스 크기는 720 x 1280 (9:16 세로형)으로 설정해줘.
2. 배경은 검은색으로 해줘.
3. 화면에 여러 개의 원들을 배치하되, 각 원의 크기와 색상은 독립적인 유전 특성으로 가지도록 해줘.
4. 특정 패턴이나 형태(예: 큰 빨간색 원 무리)를 진화의 목표로 설정해줘.
5. 매 세대마다 가장 적합한 개체들을 선택하고, 그 특성이 다음 세대에 더 많이 나타나도록 진화 시뮬레이션을 구현.
6. 시간에 따라 전체 집단의 특성이 목표에 수렴하는 과정을 시각적으로 보여줘. 색상은 진화 정도를 반영하도록.
7. 마우스를 캔버스 위에 올리면 마우스 위치의 특성을 새로운 진화 목표로 설정하도록 인터랙션을 추가해줘.
