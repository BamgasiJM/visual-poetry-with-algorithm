## **<span style="color:#1ED2C8;">프롬프트 작성 요령 및 준수 사항</span>**
1. 구현할 아트워크의 캔버스 크기, 오브젝트, 색, 움직임, 인터랙션 등을 정리하고 지시할 것.
2. 사용할 알고리즘 물감(로직)을 디테일하게 정의하고 올바른 용어를 사용해서 지시할 것.
3. 지시 순서는 캔버스 설정 > 오브젝트 묘사 > 애니메이션 >  인터랙션 설명 순으로 할 것.
4. 마음에 들지 않는 결과가 계속 반복된다면 새로운 채팅 창이나 다른 LLM에서 새로 시작할 것.
5. 수정 요청 시 전체를 바꾸어버리는 경우가 있으므로 부분만 수정 요청하거나, 수정하면 안되는 영역을 설정할 것.
6. AI가 짠 코드에는 오류가 있을 수 있으므로 필요시 다른 LLM을 이용하여 refactoring을 요청할 것.
7. 설명 주석을 요청하여 사용한 로직, 알고리즘과 함수의 의미를 파악할 것.
8. AI가 짜 준 아트워크에 만족하지 말고, 내 입맛에 맞게 변수의 값을 바꾸어 볼 것.
9. 참고할 이미지를 업로드할 때는 어느 부분을 참고해서 만들지, 개선할지 등을 자세히 지시할 것. (첨부 용량 주의)
10. 다른 사람이 만든 코드를 활용할 때에는 AI에게 코드의 로직을 물어보고 파악한 후 필요한 부분만 사용할 것. (저작권 여부 확인)

5. 지금 작성한 아트워크의 의미을 설명하고 이후 발전 방향을 제안해줘.

7. 인터랙션 여부

## **<span style="color:#f49571;">예시 프롬프트 1 - 기쁨</span>**

1. 캔버스 크기는 800 x 800으로 설정해줘.
2. 배경은 따뜻한 밝은 톤(노란색이나 밝은 주황색)으로 해줘.
3. 원들이 화면 중앙에서 퍼져 나가는 느낌으로 배치되게 해줘. 원의 크기는 중앙에서 멀어질수록 작아져야 해.
4. 원들의 색상은 빨강, 주황, 노랑 같은 따뜻한 색상으로 해줘. 각 원마다 색이 조금씩 달라지게 하고 투명도도 랜덤하게 해줘.
5. 도형의 개수는 10~15개 정도로 해줘.
6. 인터랙션과 애니메이션은 없이 정적인 결과만 나오도록 작성해줘.

## **<span style="color:#f49571;">예시 프롬프트 2 - 슬픔</span>**

1. 캔버스 크기는 1000 x 500으로 설정해줘.
2. 배경은 어두운 차가운 톤(진한 파랑이나 보라색)으로 해줘.
3. 길쭉한 세로 선들을 여러 개 그려서 마치 빗줄기가 내리는 것처럼 보이게 해줘.
4. 선들의 길이와 위치에 랜덤 값을 사용해서 불규칙적이고 자연스러운 느낌이 나게 해줘.
5. 선들의 색상은 밝은 하늘색이나 옅은 파랑으로 해서 어두운 배경과 대비되게 해줘. 투명도도 랜덤하게 변화시켜줘.
6. 화면 전체에 걸쳐 여러 선이 분포하되, 위쪽이 아래쪽보다 더 많이 보이도록 해줘.
7. 인터랙션과 애니메이션은 없이 정적인 결과만 나오도록 작성해줘.

## **<span style="color:#f49571;">예시 프롬프트 3 - 분노</span>**

1. 캔버스 크기는 960 x 1280으로 설정해줘.
2. 배경은 진한 검은색이나 검은 회색으로 해줘.
3. 중간 크기의 정사각형이나 삼각형 같은 뾰족한 도형들을 화면에 랜덤하게 배치해줘.
4. 각 도형의 크기와 위치, 회전 각도에 랜덤 값을 주되, 겹쳐도 괜찮아.
5. 도형의 색상은 빨강, 검은색, 어두운 주황색으로 해서 강렬하고 거친 느낌이 나도록 해줘. 가장자리를 선으로 강조해도 좋아.
6. 도형들의 개수는 15~20개 정도로 꽤 많이 배치해줘.
7. 인터랙션과 애니메이션은 없이 정적인 결과만 나오도록 작성해줘.
