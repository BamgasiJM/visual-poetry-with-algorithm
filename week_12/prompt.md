## **<span style="color:#1ED2C8;">프롬프트 작성 요령 및 준수 사항</span>**
1. 구현할 아트워크의 캔버스 크기, 오브젝트, 색, 움직임, 인터랙션 등을 정리하고 지시할 것.
2. 사용할 알고리즘 물감(로직)을 디테일하게 정의하고 올바른 용어를 사용해서 지시할 것.
3. 지시 순서는 캔버스 설정 > 오브젝트 묘사 > 애니메이션 >  인터랙션 설명 순으로 할 것.
4. 마음에 들지 않는 결과가 계속 반복된다면 새로운 채팅 창이나 다른 LLM에서 새로 시작할 것. 
5. 수정 요청 시 전체를 바꾸어버리는 경우가 있으므로 부분만 수정 요청하거나, 수정하면 안되는 영역을 설정할 것.
6. AI가 짠 코드에는 오류가 있을 수 있으므로 필요시 다른 LLM을 이용하여 refactoring을 요청할 것.
7. 설명 주석을 요청하여 사용한 로직, 알고리즘과 함수의 의미를 파악할 것. 
8. AI가 짜 준 아트워크에 만족하지 말고, 내 입맛에 맞게 변수의 값을 바꾸어 볼 것.
9. 참고할 이미지를 업로드할 때는 어느 부분을 참고해서 만들지, 개선할지 등을 자세히 지시할 것. (첨부 용량 주의)
10. 다른 사람이 만든 코드를 활용할 때에는 AI에게 코드의 로직을 물어보고 파악한 후 필요한 부분만 사용할 것. (저작권 여부 확인)

## **<span style="color:#f49571;">예시 프롬프트 1 - 중력의 춤</span>**

1. 캔버스 크기는 1920 x 1080 (16:9 가로형)으로 설정해줘.
2. 배경은 검은색으로 해줘.
3. 화면 위에 여러 개의 원(동적 객체)을 배치하고, 화면 중앙에 강력한 중력장(attractor)을 설정해줘.
4. 각 원은 중력장의 영향을 받아 중심을 향해 끌려가지만, 도달하기 직전에 반발력을 느껴서 밀려나갔다가 다시 돌아오는 진동하는 움직임을 표현.
5. 원들의 색상은 밝은 분홍색이나 주황색으로 하고, 속도가 빠를수록 더 밝게 표현.
6. 각 원의 궤적이 남도록 페이드 처리해서 마치 춤을 추는 듯한 시각적 효과를 만들어줘.
7. 인터랙션은 없이 자동으로 계속 반복되도록 작성해줘.

## **<span style="color:#f49571;">예시 프롬프트 2 - 척력의 분산</span>**

1. 캔버스 크기는 800 x 800 (1:1 정사각형)으로 설정해줘.
2. 배경은 밝은 회색으로 해줘.
3. 여러 개의 점들을 화면에 배치하되, 점들끼리 서로 척력(repulsion force)을 느끼도록 해줘.
4. 각 점이 다른 모든 점들로부터 밀려나면서 화면 전체에 고르게 흩어지는 모습을 표현.
5. 점들의 색상은 차분한 파란색이나 초록색으로 하고, 충돌이나 가까워질 때의 거리는 유지되도록.
6. 움직임은 완만하면서도 계속 변화하는 느낌을 주도록.
7. 인터랙션과 마우스 입력은 없도록 작성해줘.

## **<span style="color:#f49571;">예시 프롬프트 3 - 대척점의 아름다움</span>**

1. 캔버스 크기는 720 x 1280 (9:16 세로형)으로 설정해줘.
2. 배경은 검은색으로 해줘.
3. 화면에 여러 개의 움직이는 원들을 배치하되, 매력과 척력을 동시에 적용해서 복잡한 궤도 운동을 만들어줘.
4. 각 원은 중력장의 중심을 향해 끌려가면서도 다른 원들로부터는 밀려나는 상호작용을 표현.
5. 원들의 색상은 밝은 청록색이나 보라색으로 하고, 속도와 거리에 따라 색상이 변하도록.
6. 마우스를 캔버스 위에 올리면 그 위치에 임시 중력장이 생겨서 원들이 마우스 방향으로 끌려가거나 밀려나도록 인터랙션을 추가해줘.
7. 마우스가 움직일 때마다 전체 원들의 궤도가 동적으로 변하게 해줘.
