프롬프트 예시(영어):
"Write a p5.js sketch that draws a smooth, flowing line across the canvas using Perlin noise. 
The line should be animated, moving horizontally over time, and have a teal color. 
The canvas size should be 1600x900 pixels, and the animation should run at 60 frames per second. 
The line should be thick and continuous, filling the entire width of the canvas."

프롬프트 예시(한글):
"p5.js를 사용하여 페를린 노이즈(noise)를 기반으로 부드럽고 흐르는 선을 그리는 스케치를 작성해줘.
선은 애니메이션으로 시간의 흐름에 따라 가로 방향으로 이동해야 하고, 티얼 색상을 가져야 해.
캔버스 크기는 1600x900 픽셀이고, 애니메이션은 초당 60프레임으로 실행되어야 해.
선은 두껍고 연속적으로 캔버스의 전체 너비를 채워야 해."

1. 내 마음 속 감정
사랑 (Love)
두 개의 입자가 서로를 끌어당기고 합쳐져 하나의 새로운 형태를 만듦.

기쁨 (Joy)
사용자의 클릭이나 움직임에 따라 색종이처럼 다채로운 조각들이 화면 가득 날아다님.

평온 (Peace)
호수의 잔물결처럼, 사용자의 상호작용이 중심에서부터 부드럽게 천천히 퍼져나감.

희망 (Hope)
어두운 화면 속에서 한 줄기 빛이나 새싹이 자라나듯, 점점 밝고 커지는 형태.

해방감 (Liberation)
갇혀 있던 입자들이 터져 나와 자유롭게 공간을 날아다님.

설렘 (Fluttering Heart)
심장박동처럼 규칙적이면서도 점점 커지는 원이나 형태, 밝은 색상의 반짝임.

활기참 (Vibrancy)
밝고 선명한 색상의 입자들이 에너지 있게 터져 나와 화면을 채움.

감사함 (Gratitude)
빛이나 따뜻한 색의 입자들이 한 곳으로 모여들어 점점 더 커지는 빛 덩어리를 형성.

화남 (Anger)
날카롭고 어두운 형태가 빠르고 거친 움직임으로 화면을 가득 채우거나, 흔들림 효과.

슬픔 (Sadness)
비처럼 내리는 입자들이 바닥에 닿아 퍼지거나, 화면 전체가 점차 흑백으로 변함.

불안감 (Anxiety)
선들이 미세하게 계속 떨리거나, 화면이 순간적으로 깜빡이는 노이즈 효과.

피곤함 (Fatigue)
움직임이 점점 느려지고, 색이 바래거나 형태가 무너져 내림.

혼란 (Confusion)
여러 방향을 가리키는 화살표, 겹쳐진 텍스트, 예측 불가능한 움직임이 뒤섞임.

지루함 (Boredom)
같은 패턴이 아주 느리게 반복되거나, 아무런 상호작용도 일어나지 않는 정적인 화면.

2. 관계 및 사회적 감정
연결 (Connection)
점과 점을 잇는 선이 사용자의 상호작용에 따라 생성되고, 점점 더 복잡한 네트워크를 만듦.

우정 (Friendship)
여러 개의 입자가 함께 움직이며 서로를 밀어주거나, 방해물을 함께 막아냄.

공감 (Empathy)
두 개의 형태가 서로의 색이나 움직임, 모양을 서서히 닮아가는 과정.

외로움 (Loneliness)
넓은 공간에 오직 하나의 입자만이 희미하게 빛나거나, 천천히 움직임.

소속감 (Belonging)
흩어져 있던 작은 입자들이 하나의 큰 형태(예: 동물, 사람 모양)를 이루며 안정감을 줌.

질투 (Jealousy)
특정 대상을 중심으로 다른 것들을 가리거나, 시야를 왜곡시키는 장애물이 생김.

3. 복합적 감정
향수 (Nostalgia)
오래된 필름처럼 빛바랜 색감과 노이즈 속에서 희미한 이미지가 나타났다 사라짐.

몰입&집중 (Focus)
복잡한 배경이 점점 단순해지고, 오직 하나의 점이나 선에만 집중되는 시각 효과.

성장 (Growth)
마우스를 따라 싹이 트고 나뭇가지가 뻗어나가며 점점 복잡한 형태가 됨.

기대감 (Anticipation)
무언가 터져 나오기 직전의 팽팽한 긴장감, 예를 들어 수면 위로 올라오는 거품.
