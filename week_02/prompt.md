**필수 지시 문장**
p5.js로 제너레이티브 아트워크를 만들기 위한 코드를 작성해줘.

1. p5.js 에디터에서 실행할 것이므로 instance mode가 아닌 global mode로 작성해줘.
2. HTML, CSS 파일 없이 자바스크립트 코드만 작성해줘.
3. react 같은 외부 라이브러리는 사용하지 말고 vanilla JS만 사용해줘.
4. 코딩 경험이 없으므로 설명을 위한 쉬운 한글 주석을 달아줘. 변수와 메서드의 의미를 설명해줘.

**예시 프롬프트 1**
캔버스 크기는 800 x 800 정사각형으로 설정해줘.
배경은 밝지 않은 중간 톤으로 해줘.

원, 타원, 사각형 같은 기본 도형들을 여러 개 사용해서
하나의 큰 감정 덩어리처럼 보이는 조형을 만들어줘.

도형들은 서로 겹쳐도 괜찮고, 약간의 랜덤 값을 사용해서 완벽히 정렬되지 않게 해줘.

색상은 흰색만 사용하고 투명도를 랜덤하게 적용해줘.

인터랙션과 애니메이션은 없이 정적인 결과만 나오도록 작성해줘.

**예시 프롬프트 2**
화면 왼쪽에서 오른쪽으로
형태가 이어지는 듯한 구성을 만들어줘.

짧은 선, 점, 얇은 사각형들을 반복적으로 배치해서
하나의 흐름이나 방향성이 느껴지도록 해줘.

위치나 길이에 랜덤 값을 사용하되, 전체적으로는 가로 방향의 리듬이 유지되게 해줘.

색상은 대비가 느껴지는 조합을 사용하고, 형태마다 색이 조금씩 달라지게 해줘.

인터랙션과 애니메이션은 없이 정적인 결과만 나오도록 작성해줘.

**예시 프롬프트 3**
캔버스 크기는 720 x 1280 (9:16 세로형)으로 설정해줘.
배경은 밝지 않은 단색으로 해줘.

아래에서 위로 형태가 쌓여 올라간 것처럼 보이는
조형 구조를 만들어줘.

작은 도형들을 여러 줄로 반복 배치해서 층이 생기는 느낌을 표현해줘.

각 층마다 색상이 조금씩 달라지도록 하고,
전체적으로는 하나의 색 계열 안에서 변화하도록 해줘.

노이즈나 랜덤을 사용해 완벽히 똑같지 않은 형태가 되게 해줘.

인터랙션과 애니메이션은 없이 정적인 결과만 나오도록 작성해줘.
