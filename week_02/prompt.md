## **<span style="color:#1ED2C8;">프롬프트 작성 요령 및 준수 사항</span>**
1. 구현할 아트워크의 캔버스 크기, 오브젝트, 색, 움직임, 인터랙션 등을 정리하고 지시할 것.
2. 사용할 알고리즘 물감(로직)을 디테일하게 정의하고 올바른 용어를 사용해서 지시할 것.
3. 지시 순서는 캔버스 설정 > 오브젝트 묘사 > 애니메이션 >  인터랙션 설명 순으로 할 것.
4. 마음에 들지 않는 결과가 계속 반복된다면 새로운 채팅 창이나 다른 LLM에서 새로 시작할 것.
5. 수정 요청 시 전체를 바꾸어버리는 경우가 있으므로 부분만 수정 요청하거나, 수정하면 안되는 영역을 설정할 것.
6. AI가 짠 코드에는 오류가 있을 수 있으므로 필요시 다른 LLM을 이용하여 refactoring을 요청할 것.
7. 설명 주석을 요청하여 사용한 로직, 알고리즘과 함수의 의미를 파악할 것.
8. AI가 짜 준 아트워크에 만족하지 말고, 내 입맛에 맞게 변수의 값을 바꾸어 볼 것.
9. 참고할 이미지를 업로드할 때는 어느 부분을 참고해서 만들지, 개선할지 등을 자세히 지시할 것. (첨부 용량 주의)
10. 다른 사람이 만든 코드를 활용할 때에는 AI에게 코드의 로직을 물어보고 파악한 후 필요한 부분만 사용할 것. (저작권 여부 확인)

5. 지금 작성한 아트워크의 의미을 설명하고 이후 발전 방향을 제안해줘.

## **<span style="color:#f49571;">예시 프롬프트 1</span>**

1. 캔버스 크기는 1920 x 1080으로 설정해줘.
2. 배경은 밝지 않은 중간 톤으로 해줘.
3. 원, 타원, 사각형 같은 기본 도형들을 여러 개 사용해서 하나의 큰 감정 덩어리처럼 보이는 조형 요소를 만들어줘.
4. 도형들은 서로 겹쳐도 괜찮고, 약간의 랜덤 값을 사용해서 완벽히 정렬되지 않게 해줘.
5. 색상은 흰색만 사용하고 투명도를 랜덤하게 적용해줘.
6. 인터랙션과 애니메이션은 없이 정적인 결과만 나오도록 작성해줘.

## **<span style="color:#f49571;">예시 프롬프트 2</span>**

1. 캔버스 크기는 800 x 800 정사각형으로 설정해줘.
2. 화면 왼쪽에서 오른쪽으로 형태가 이어지는 듯한 구성을 만들어줘.
3. 짧은 선, 점, 얇은 사각형들을 반복적으로 배치해서 하나의 흐름이나 방향성이 느껴지도록 해줘.
4. 위치나 길이에 랜덤 값을 사용하되, 전체적으로는 가로 방향의 리듬이 유지되게 해줘.
5. 색상은 대비가 느껴지는 조합을 사용하고, 형태마다 색이 조금씩 달라지게 해줘.
6. 인터랙션과 애니메이션은 없이 정적인 결과만 나오도록 작성해줘.

## **<span style="color:#f49571;">예시 프롬프트 3</span>**

1. 캔버스 크기는 720 x 1280 (9:16 세로형)으로 설정해줘.
2. 배경은 밝지 않은 단색으로 해줘.
3. 아래에서 위로 형태가 쌓여 올라간 것처럼 보이는 조형 구조를 만들어줘.
4. 작은 도형들을 여러 줄로 반복 배치해서 층이 생기는 느낌을 표현해줘.
5. 각 층마다 색상이 조금씩 달라지도록 하고, 전체적으로는 하나의 색 계열 안에서 변화하도록 해줘.
6. 노이즈나 랜덤을 사용해 완벽히 똑같지 않은 형태가 되게 해줘.
7. 인터랙션과 애니메이션은 없이 정적인 결과만 나오도록 작성해줘.
