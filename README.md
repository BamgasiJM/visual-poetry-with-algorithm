✨ 수업 소개:
마음을 그리는 알고리즘 물감 (Visual Poetics through Algorithms)

우리는 코딩을 배우지 않습니다. 새로운 물감을 다룹니다.

붓 대신 알고리즘을, 유화 물감 대신 데이터를 사용하여 우리의 내면을 캔버스에 펼쳐내는 창의적 여정입니다. 이 수업은 기술 습득을 넘어, 코드 작성, 규칙 설계, 반복 실행이라는 행위를 통해 가장 추상적이고 개인적인 영역인 '마음'을 탐색하고 시각화합니다.

15주 동안, 우리는 불안, 우연, 관계, 시간 같은 복합적인 감정들을 주제로 삼아, p5.js 환경에서 AI를 공동 창작자(물감 제조사)로 활용하는 혁신적인 방식으로 아트워크를 완성합니다.

당신의 알고리즘은 무엇을 그리고 있습니까? 캔버스가 된 화면 위에서 당신의 내면 풍경을 조형적으로 펼쳐내 보세요.
