## **<span style="color:#1ED2C8;">프롬프트 작성 요령 및 준수 사항</span>**
1. 구현할 아트워크의 캔버스 크기, 오브젝트, 색, 움직임, 인터랙션 등을 정리하고 지시할 것.
2. 사용할 알고리즘 물감(로직)을 디테일하게 정의하고 올바른 용어를 사용해서 지시할 것.
3. 지시 순서는 캔버스 설정 > 오브젝트 묘사 > 애니메이션 >  인터랙션 설명 순으로 할 것.
4. 마음에 들지 않는 결과가 계속 반복된다면 새로운 채팅 창이나 다른 LLM에서 새로 시작할 것. 
5. 수정 요청 시 전체를 바꾸어버리는 경우가 있으므로 부분만 수정 요청하거나, 수정하면 안되는 영역을 설정할 것.
6. AI가 짠 코드에는 오류가 있을 수 있으므로 필요시 다른 LLM을 이용하여 refactoring을 요청할 것.
7. 설명 주석을 요청하여 사용한 로직, 알고리즘과 함수의 의미를 파악할 것. 
8. AI가 짜 준 아트워크에 만족하지 말고, 내 입맛에 맞게 변수의 값을 바꾸어 볼 것.
9. 참고할 이미지를 업로드할 때는 어느 부분을 참고해서 만들지, 개선할지 등을 자세히 지시할 것. (첨부 용량 주의)
10. 다른 사람이 만든 코드를 활용할 때에는 AI에게 코드의 로직을 물어보고 파악한 후 필요한 부분만 사용할 것. (저작권 여부 확인)

## **<span style="color:#f49571;">예시 프롬프트 1 - 노이즈 필드의 흐름</span>**

1. 캔버스 크기는 1920 x 1080 (16:9 가로형)으로 설정해줘.
2. 배경은 검은색으로 해줘.
3. 화면 전체에 Perlin 노이즈 기반의 벡터 필드를 생성해줘. (각 위치에 방향을 가지는 필드)
4. 많은 수의 파티클들을 화면에 배치하고, 각 파티클이 이 노이즈 필드를 따라 움직이도록.
5. 파티클의 색상은 밝은 청록색이나 라임색으로 하고, 움직임의 궤적이 남도록 페이드 처리.
6. 노이즈 필드가 시간에 따라 천천히 변하도록 해서 움직임이 계속 변화하는 모습이 보이도록.
7. 인터랙션은 없이 자동으로 흐르도록 작성해줘.

## **<span style="color:#f49571;">예시 프롬프트 2 - 소용돌이</span>**

1. 캔버스 크기는 800 x 800 (1:1 정사각형)으로 설정해줘.
2. 배경은 진한 회색이나 남색으로 해줘.
3. 화면 중앙을 중심으로 원형 소용돌이를 만들어줘. 파티클들이 중심을 향해 빨려들어가는 모습을 표현.
4. 노이즈 필드를 사용하되, 회전 성분을 추가해서 소용돌이 효과를 만들어줘.
5. 파티클의 색상은 밝은 흰색이나 옅은 파란색으로 하고, 중심으로 갈수록 색이 밝아지도록.
6. 파티클이 중심에 도달하면 사라지고 화면 끝에서 새로 생성되도록.
7. 인터랙션과 마우스 입력은 없도록 작성해줘.

## **<span style="color:#f49571;">예시 프롬프트 3 - 폭풍의 눈</span>**

1. 캔버스 크기는 720 x 1280 (9:16 세로형)으로 설정해줘.
2. 배경은 검은색으로 해줘.
3. Perlin 노이즈 필드 위에 강력한 중력장을 추가해서 매우 역동적인 움직임을 표현해줘.
4. 파티클들이 화면 전체에 흩어졌다가 갑자기 한곳으로 모여 소용돌이를 이루는 모습을 반복하도록.
5. 파티클의 색상은 검은색에서 밝은 노랑으로 변하는 그라데이션 효과를 사용해서 에너지 느낌을 표현.
6. 마우스를 캔버스 위에 올리면 그 지점이 새로운 중력 중심이 되어 파티클들이 끌려가도록 인터랙션을 추가해줘.
7. 마우스를 움직일 때마다 파티클들의 흐름이 동적으로 변하게 해줘.
