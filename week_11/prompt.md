## **<span style="color:#1ED2C8;">프롬프트 작성 요령 및 준수 사항</span>**
1. 구현할 아트워크의 캔버스 크기, 오브젝트, 색, 움직임, 인터랙션 등을 정리하고 지시할 것.
2. 사용할 알고리즘 물감(로직)을 디테일하게 정의하고 올바른 용어를 사용해서 지시할 것.
3. 지시 순서는 캔버스 설정 > 오브젝트 묘사 > 애니메이션 >  인터랙션 설명 순으로 할 것.
4. 마음에 들지 않는 결과가 계속 반복된다면 새로운 채팅 창이나 다른 LLM에서 새로 시작할 것. 
5. 수정 요청 시 전체를 바꾸어버리는 경우가 있으므로 부분만 수정 요청하거나, 수정하면 안되는 영역을 설정할 것.
6. AI가 짠 코드에는 오류가 있을 수 있으므로 필요시 다른 LLM을 이용하여 refactoring을 요청할 것.
7. 설명 주석을 요청하여 사용한 로직, 알고리즘과 함수의 의미를 파악할 것. 
8. AI가 짜 준 아트워크에 만족하지 말고, 내 입맛에 맞게 변수의 값을 바꾸어 볼 것.
9. 참고할 이미지를 업로드할 때는 어느 부분을 참고해서 만들지, 개선할지 등을 자세히 지시할 것. (첨부 용량 주의)
10. 다른 사람이 만든 코드를 활용할 때에는 AI에게 코드의 로직을 물어보고 파악한 후 필요한 부분만 사용할 것. (저작권 여부 확인)

## **<span style="color:#f49571;">예시 프롬프트 1</span>**

1. 사람 사이의 거리와 감정의 흐름을 표현하는 추상 아트워크를 만들어줘. 캔버스는 800 x 800 크기로 설정하고, 어두운 배경 위에 빛나는 선과 점들이 떠 있는 분위기로 구성해줘.
2. 화면 왼쪽에는 조밀하고 가까운 형태들을 배치하고, 오른쪽으로 갈수록 요소들이 점점 멀어지며 흩어지게 만들어줘. 전체적으로 관계가 연결되었다가 서서히 멀어지는 감정의 흐름이 느껴지게 해줘.
3. 짧은 수평선, 작은 점, 매우 얇은 직사각형들을 반복적으로 배치해서 바람이나 신호가 옆으로 흘러가는 듯한 방향감을 만들어줘.
4. 각 요소의 위치와 길이는 랜덤하게 생성하되, y축 변화는 작게 유지해서 가로 방향의 리듬이 계속 이어지게 해줘.
5. dist() 함수를 사용해서 가까운 요소들끼리는 가는 선으로 연결하고, 거리가 멀어질수록 연결선이 사라지거나 투명해지게 만들어줘.
6. 색상은 검정 배경 위에 흰색, 붉은색, 청록색 계열을 섞어서 사용하고, 형태마다 색이 조금씩 달라져 감정의 온도 차이가 느껴지게 해줘.

## **<span style="color:#f49571;">예시 프롬프트 2</span>**

1. 사람들 사이의 보이지 않는 심리적 거리와 관계의 긴장감을 표현하는 추상 아트워크를 만들어줘. 캔버스는 800 x 800 크기로 설정하고, 전체 분위기는 조용하지만 불안정한 감정이 느껴지게 구성해줘.
2. 화면 중앙에는 비교적 밀집된 점들과 선들을 배치하고, 바깥쪽으로 갈수록 형태가 드물어지고 끊어지게 만들어줘. 마치 사람들이 가까이 모여 있지만 서로 완전히 연결되지는 못하는 느낌이 들게 표현해줘.
3. 매우 얇은 선, 작은 원, 긴 직사각형 조각들을 반복적으로 사용해서 미세한 떨림이나 신호 같은 시각적 흐름을 만들어줘. 일부 선들은 서로 연결되고, 일부는 중간에서 끊어진 상태로 남겨줘.
4. dist() 함수를 사용해서 가까운 요소들끼리는 연결선이 생성되도록 하고, 거리가 멀어질수록 연결선의 투명도와 두께가 줄어들게 해줘.
5. 전체 구성은 완전히 랜덤하지 않게 하고, 화면 중심을 기준으로 관계가 형성되는 듯한 방향성을 유지해줘. 랜덤한 위치 변화 속에서도 하나의 감정적 구조가 느껴지게 만들어줘.
6. 색상은 어두운 남색 또는 검은 배경 위에 흰색, 흐린 분홍색, 옅은 청록색을 섞어서 사용하고, 일부 요소만 밝게 빛나도록 표현해줘.
