## **<span style="color:#1ED2C8;">프롬프트 작성 요령 및 준수 사항</span>**
1. 구현할 아트워크의 캔버스 크기, 오브젝트, 색, 움직임, 인터랙션 등을 정리하고 지시할 것.
2. 사용할 알고리즘 물감(로직)을 디테일하게 정의하고 올바른 용어를 사용해서 지시할 것.
3. 지시 순서는 캔버스 설정 > 오브젝트 묘사 > 애니메이션 >  인터랙션 설명 순으로 할 것.
4. 마음에 들지 않는 결과가 계속 반복된다면 새로운 채팅 창이나 다른 LLM에서 새로 시작할 것. 
5. 수정 요청 시 전체를 바꾸어버리는 경우가 있으므로 부분만 수정 요청하거나, 수정하면 안되는 영역을 설정할 것.
6. AI가 짠 코드에는 오류가 있을 수 있으므로 필요시 다른 LLM을 이용하여 refactoring을 요청할 것.
7. 설명 주석을 요청하여 사용한 로직, 알고리즘과 함수의 의미를 파악할 것. 
8. AI가 짜 준 아트워크에 만족하지 말고, 내 입맛에 맞게 변수의 값을 바꾸어 볼 것.
9. 참고할 이미지를 업로드할 때는 어느 부분을 참고해서 만들지, 개선할지 등을 자세히 지시할 것. (첨부 용량 주의)
10. 다른 사람이 만든 코드를 활용할 때에는 AI에게 코드의 로직을 물어보고 파악한 후 필요한 부분만 사용할 것. (저작권 여부 확인)

## **<span style="color:#f49571;">예시 프롬프트 1 - 가까운 거리</span>**

1. 캔버스 크기는 1920 x 1080 (16:9 가로형)으로 설정해줘.
2. 배경은 밝은 베이지색이나 옅은 파란색으로 해줘.
3. 화면에 여러 개의 점들(노드)을 배치하고, dist() 함수를 사용해서 점들 사이의 거리를 계산해줘.
4. 거리가 일정 이하인 점들끼리 선으로 연결하되, 거리가 가까울수록 선이 굵고 밝게 보이도록.
5. 각 점의 색상은 차분한 파란색으로 하고, 연결선의 색상은 거리에 따라 투명도가 변하도록.
6. 점들은 정적으로 배치되어 있고, 연결 관계만 보이도록.
7. 인터랙션과 애니메이션은 없이 정적인 결과만 나오도록 작성해줘.

## **<span style="color:#f49571;">예시 프롬프트 2 - 먼 거리</span>**

1. 캔버스 크기는 800 x 800 (1:1 정사각형)으로 설정해줘.
2. 배경은 검은색으로 해줘.
3. 화면 중앙에 여러 개의 점들을 뭉쳐 배치하되, 몇 개의 점들은 화면 가장자리에 떨어져 있게 해줘.
4. dist() 함수를 사용해서 점들 사이의 거리를 계산하고, 거리에 따라 연결선의 투명도를 조절해줘.
5. 가까운 점들은 밝은 선으로 강하게 연결되고, 먼 점들은 매우 희미하거나 연결되지 않도록.
6. 점들의 색상은 밝은 분홍색이나 주황색으로 하되, 고립된 점은 더 어두운 색으로.
7. 인터랙션과 애니메이션은 없이 정적인 결과만 나오도록 작성해줘.

## **<span style="color:#f49571;">예시 프롬프트 3 - 상호 작용</span>**

1. 캔버스 크기는 720 x 1280 (9:16 세로형)으로 설정해줘.
2. 배경은 검은색으로 해줘.
3. 화면에 여러 개의 점들을 무작위로 배치하고, 각 점이 이동하면서 동적으로 변하는 거리 관계를 표현해줘.
4. 각 점은 sin 함수를 사용해서 느리게 움직이도록 (sin에 기반한 애니메이션).
5. 거리가 일정 이상 가까워지면 연결선이 나타나고, 멀어지면 사라지도록. 연결선의 색상도 거리에 따라 변하도록.
6. 점의 색상은 밝은 청록색이나 옅은 보라색으로 하되, 많은 점과 연결된 점은 더 밝게 표현.
7. 마우스를 캔버스 위에 올리면 마우스 위치가 임시로 새로운 점이 되어 주변 점들과의 거리 관계에 영향을 주도록 인터랙션을 추가해줘.
