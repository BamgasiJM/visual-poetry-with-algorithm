## **<span style="color:#1ED2C8;">프롬프트 작성 요령 및 준수 사항</span>**
1. 구현할 아트워크의 캔버스 크기, 오브젝트, 색, 움직임, 인터랙션 등을 정리하고 지시할 것.
2. 사용할 알고리즘 물감(로직)을 디테일하게 정의하고 올바른 용어를 사용해서 지시할 것.
3. 지시 순서는 캔버스 설정 > 오브젝트 묘사 > 애니메이션 >  인터랙션 설명 순으로 할 것.
4. 마음에 들지 않는 결과가 계속 반복된다면 새로운 채팅 창이나 다른 LLM에서 새로 시작할 것. 
5. 수정 요청 시 전체를 바꾸어버리는 경우가 있으므로 부분만 수정 요청하거나, 수정하면 안되는 영역을 설정할 것.
6. AI가 짠 코드에는 오류가 있을 수 있으므로 필요시 다른 LLM을 이용하여 refactoring을 요청할 것.
7. 설명 주석을 요청하여 사용한 로직, 알고리즘과 함수의 의미를 파악할 것. 
8. AI가 짜 준 아트워크에 만족하지 말고, 내 입맛에 맞게 변수의 값을 바꾸어 볼 것.
9. 참고할 이미지를 업로드할 때는 어느 부분을 참고해서 만들지, 개선할지 등을 자세히 지시할 것. (첨부 용량 주의)
10. 다른 사람이 만든 코드를 활용할 때에는 AI에게 코드의 로직을 물어보고 파악한 후 필요한 부분만 사용할 것. (저작권 여부 확인)

## **<span style="color:#f49571;">예시 프롬프트 1 - 무작위 산책</span>**

1. 캔버스 크기는 1920 x 1080 (16:9 가로형)으로 설정해줘.
2. 배경은 밝은 회색이나 베이지색으로 해줘.
3. 화면 중앙에서 시작하는 하나의 선이 화면 위를 계속 움직이며 그려지도록 해줘. (마치 술취한 사람이 거니는 것처럼 random walk)
4. 매 프레임마다 선이 상하좌우 중 하나의 방향으로 랜덤하게 이동하도록 해줘.
5. 선의 색상은 부드러운 파란색이나 보라색으로 하고, 시간에 따라 투명도가 조금씩 변하도록.
6. 선이 이미 지나간 경로는 희미하게 남아있다가 점점 사라지는 페이드 효과를 넣어줘.
7. 인터랙션은 없이 자동으로 계속 움직이도록 작성해줘.

## **<span style="color:#f49571;">예시 프롬프트 2 - 세포의 성장</span>**

1. 캔버스 크기는 800 x 800 (1:1 정사각형)으로 설정해줘.
2. 배경은 검은색으로 해줘.
3. 화면을 격자로 나누고 (예: 20x20 칸), 각 칸이 살아있거나 죽어있는 상태를 가지도록 해줘. (셀룰러 오토마타)
4. 처음에는 몇 개의 셀만 살아있고, 매 세대마다 일정한 규칙에 따라 주변 셀들에 전파되도록.
5. 살아있는 셀은 밝은 초록색이나 옅은 파란색으로 표시하고, 죽은 셀은 어두운 색으로.
6. 애니메이션은 자동으로 계속 진행되게 하되, 매 세대마다 패턴이 변하고 성장하는 모습이 보여야 해.
7. 인터랙션과 마우스 입력은 없도록 작성해줘.

## **<span style="color:#f49571;">예시 프롬프트 3 - 흔들림의 궤적</span>**

1. 캔버스 크기는 720 x 1280 (9:16 세로형)으로 설정해줘.
2. 배경은 진한 파랑이나 보라색으로 해줘.
3. 화면에 여러 개의 점들(파티클)을 분산시켜 배치해줘. (10~20개 정도)
4. 각 점마다 독립적인 random walk를 구현해서 매 프레임마다 주변으로 조금씩 흔들리며 움직이게 해줘.
5. 각 점의 색상은 밝은 분홍색이나 흰색으로 하고, 점들 사이에 거리에 따라 연결선을 그려줘. (가까우면 선이 굵고 밝음)
6. 마우스를 캔버스 위에 올리면 그 지점으로 모든 점들이 끌려가도록 인터랙션을 추가해줘. (mouseX, mouseY 활용)
7. 마우스가 움직임에 따라 점들의 움직임도 함께 변하도록 해줘.
